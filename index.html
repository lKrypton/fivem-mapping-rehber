Sıfırdan FiveM map ve MLO

Blender ile modelle, Sollumz ile GTA formatına çevir, CodeWalker ile oyuna yerleştir. Bu sayfa o üçgeni Türkçe ve kısa anlatıyor.

Kural basit: her gün bir şey yap ve oyunda gör. Video izlemek ilerleme sayılmaz.

10 günlük plan Günde 1-2 saat. Tikleri bu tarayıcıda saklanır.

1. Kurulum

CodeWalker

  1. CodeWalker Discord'una gir. #releases kanalından son sürümü indir.
  2. Aynı sunucuda #tips-documentation kanalında "updated nametables" mesajını bul, nametables.rpf dosyasını indir.
  3. CodeWalker zip'ini bir klasöre çıkar (ör. C:\Araclar\CodeWalker).
  4. CodeWalker RPF Explorer.exe'yi aç. GTA V klasörünü sorarsa göster.
  5. Üstte Options → Start in Edit Mode'u aç. (İstersen View → Theme → Dark.)
  6. GTA klasörünün kökünde sağ tık → New → RPF Archive. Adı ör. 3dmods. Testlerini buraya atacaksın.
  7. nametables.rpf'yi RPF Explorer'da GTA kök klasörüne sürükle bırak.

Blender + Sollumz

  1. Blender 4.5 LTS'i kur ve aç.
  2. Edit → Preferences → Get Extensions. Sağ üstte Repositories → + → Add Remote Repository.
  3. Adres olarak https://repo.sollumz.org/ yaz.
  4. Arama kutusuna Sollumz yaz. "Sollumz" olanı kur, "(Development)" olanı değil.
  5. pyMateria kurmak isteyip istemediğini sorarsa Install de.
  6. 3D görünümde N → sağ panelde Sollumz Tools sekmesi görünüyorsa tamam.
Alternatif: repo eklemek çalışmazsa GitHub'dan Sollumz.zip indir, Get Extensions → sağ üst ok → Install from Disk. Repo yöntemi güncellemeleri otomatik getirdiği için daha iyi.

2. Oyundan model çekme Amaç: GTA'daki bir modeli Blender'a alıp geri göndermeyi öğrenmek.

CodeWalker ayarı (bir kere)

  1. CodeWalker.exe'yi aç, yüklenmesini bekle. T ile araç çubuğunu aç.
  2. Sağ panelde DLC Level listesinden en alttakini seç, Enable DLCs'i işaretle.
  3. Options → Save Settings.

Modeli çek

  1. Araç çubuğunda Select Object'i aç, istediğin objeye tıkla.
  2. Sağ üst panelden objenin adını kopyala.
  3. Tools → RPF Explorer'da adı ara. Dosyaya sağ tık → Export XML.
  4. Dosyaya çift tıkla, soldaki Materials sekmesinde Save All Textures. Aynı klasöre kaydet.

Blender'a al, geri gönder

  1. Blender'da N → Sollumz Tools → General → Import CodeWalker XML. Ayarlar varsayılan kalsın.
  2. Doku pembe görünüyorsa: V → Find Missing Textures → dokuları kaydettiğin klasör.
  3. Bir değişiklik yap. Sonra Export CodeWalker XML.
  4. RPF Explorer'da 3dmods arşivini aç, XML'i içine sürükle. CodeWalker onu GTA formatına çevirir.

3. Kendi objeni oyuna hazırlamak

Malzeme ve doku

  1. Modeli seç. Sollumz Tools → Drawable → Shader Tools. Listede Ctrl+F ile shader ara.
    Sadece renk + normal map varsa normal, parlaklık haritası da varsa normal_spec.
  2. Create Shader Material.
  3. Sağdaki Material sekmesi → Sollumz → Texture Parameters. Klasör ikonuyla her yuvaya dokusunu ver:
    DiffuseSampler = renk, BumpSampler = normal map, SpecSampler = parlaklık.
  4. BumpSampler'ın renk alanını Non-Color yap. Yapmazsan Blender'da yanlış görünür (oyunda sorun olmaz).
  5. Ayrı ytd ile uğraşmamak için dokuları Embedded yap (Set all Textures Embedded).
  6. Doku yamuk oturduysa UV Editing sekmesi → yüzleri seç → U → Unwrap.

Vertex color ve UV adı

  1. Data (yeşil üçgen) sekmesi → Color Attributes. Var olanı sil, + ile yenisini aç:
    Ad Color 1, Domain Face Corner, Data Type Byte Color.
  2. Rengi ver: dış mekan objesi → kırmızı, interior → yeşil. (MLO rehberinde yeşil 0.2, diğerleri 0 kullanılıyor.)
  3. UV Maps'te adın UVMap 0 olduğundan emin ol.

Drawable ve ytyp

  1. Mesh seçiliyken V → Convert to Drawable.
  2. Sollumz Tools → Archetype Definition → + ile yeni YTYP, adını ver.
  3. Drawable seçiliyken Auto-Create From Selected → Export YTYP.
  4. V → Export RAGE Assets, ayarlar Native ve Gen8.
  5. Çıkan dosyaları 3dmods arşivine sürükle, CodeWalker'ı yeniden başlat, modeli kontrol et.
Export öncesi: objenin ölçeğini Ctrl+A → Scale ile uygula. Gizli (göz kapalı) objeler export edilmez.

4. Yerleştirme ve FiveM resource

CodeWalker'da ymap

  1. World View'da sol üstten proje panelini aç. File → New → Ymap File.
  2. Ymap seçiliyken üst menü Ymap → New Entity.
  3. Entity'nin Archetype alanına modelinin adını yaz. Gizmo ile taşı, döndür. Shift+sürükle kopyalar.
  4. Bitince ymap'i seç: Calculate Extents ve Calculate All Flags.
  5. Ymap'i anlaşılır bir adla kaydet.
  6. Tools → Manifest Generator → Generate, _manifest.ymf olarak kaydet.

Resource klasörü

resources/
  benim_map/

    stream/
      masa.ydr

fxmanifest.lua:

fx_version 'cerulean'
game 'gta5'
lua54 'yes'
this_is_a_map 'yes'

server.cfg'ye ensure benim_map ekle, sunucuyu başlat, git bak.

5. Collision Collision yoksa içinden geçersin ya da yerden düşersin.

Modelin içine gömülü collision

  1. Drawable seçili: Sollumz Tools → Collisions → Create Bounds → Create Bound.
  2. Oluşan Bound Composite'i seç, listeden Bound GeometryBVH seçip tekrar Create Bounds.
  3. Bound GeometryBVH seçiliyken V → Apply Flag Preset.
  4. Collision şekillerini yap (modelin sade bir kopyası ya da kutular), BVH'nin altına parent'la.
  5. Her şeklin tipi doğru olsun: mesh için Bound Poly Mesh, kutu için Bound Poly Box. Her birine collision materyali ver (beton, ahşap…). Ayak sesi ve mermi sesi buna göre çıkar.
En sık hata: Bound GeometryBVH'ye flag preset uygulamamak. Collision var görünür ama oyunda çalışmaz.
Performans: mümkünse kutu, kapsül, küre gibi basit şekiller kullan. Detaylı mesh'i collision yapma.

Dünyadaki bir collision'ı düzenlemek

  1. World View sağ panel → Selection sekmesi → Entity yerine Collision seç.
  2. Collision'a tıkla, .ybn adını kopyala, RPF Explorer'dan XML export et.
  3. Blender'a al, düzenle, tekrar export et.

Not: binaların genelde iki collision'ı vardır. isim.ybn yürümek için, hi@isim.ybn mermiler için. Kapı açıyorsan ikisini de düzenle.

6. İlk MLO Tek ya da iki odalı küçük bir binayla başla.

1. Bina seç ve dosyaları çek
  1. CodeWalker'da küçük, tek katlı bir bina bul. Adını kopyala.
  2. RPF Explorer'da bul, Export XML, dokuları bina adında bir klasöre kaydet.
  3. Dosyaya sağ tık → Open file location. Çevredeki zemin, decal ve objeleri de al: .ydr .ytd .ybn .yft .ymf.
  4. Collision'ın iki sürümünü de al: isim.ybn ve hi@isim.ybn.
  5. Binanın bulunduğu .ymap'leri export et. Ymap adı sağdaki Information panelinde yazar.
2. Plan (opsiyonel)

Kağıda ya da Excalidraw'a kabaca kat planı çiz: kaç oda, kapı nerede, ne tarz. Ölçek şart değil.

3. Blender'a al ve modelle
  1. Önce sadece .ydr ve .ybn'leri import et. Ymap'i en son al.
  2. Binayı bul, Numpad . ile odaklan.
  3. Hizalama: binanın çatısında bir yüz seç → Numpad 7 → 3D imleci oraya koy. N → View sekmesinde imlecin X ve Y dönüşünü sıfırla. Yeni bir plane ekle, sol alttaki panelde Align → 3D Cursor.
  4. Merkeze al: modeli Alt+D ile kopyala, sağ tıkla iptal et, adını Konum yap. Bu kopya gerçek konumu hatırlar. Orijinali Alt+G ve Alt+R ile sıfır noktasına al.
  5. Plane'den başlayarak zemin, duvar, tavan yap. Kabuktan kapıyı kes.
  6. Hepsini seç → Sollumz Tools → Drawable → Convert to Drawable. LOD olarak sadece High yeter.
4. Doku ve vertex color

Adım 3'teki gibi. Her oda için zemin, duvar, tavan malzemesi aç. Shader olarak normal yeter. Vertex color: yeşil 0.2, kırmızı ve mavi 0.

Kanal anlamları: kırmızı = gece kararması, yeşil = yapay ışık, mavi = ay ışığı.

5. Collision
  1. Bina collision'ında (her iki ybn) kapı yerine delik aç. Kamerayla içeri gir, yolu kesen collision kalmasın.
  2. Interior collision'ı için kabuğu Shift+D ile kopyala, sağ tıkla iptal, Alt+P ile hiyerarşiden çıkar.
  3. Kopya seçili: V → Convert to Composite, sonra Apply flag preset.
  4. Her yüze uygun collision materyali ver. Her odanın zemini ayrı materyal olsun (oda ID'si buna bağlanır).
6. YTYP: odalar ve portallar (en kritik kısım)
  1. Sollumz Tools → Archetype Definition → YTYPS → +.
  2. Drawable'ı seç, tipi base olsun, Auto-Create From Selected.
  3. Collision'ı seç, tipi MLO yap, yine Auto-Create From Selected.
  4. MLO seçiliyken Rooms sekmesi → önce Create Limbo Room. Sonra her oda için +.
  5. Oda sınırı: collision'da Edit Mode → o odanın köşe noktalarını seç → Set Bounds From Selection.
  6. Portals sekmesi → kapının 4 köşesini seç → portal oluştur. Yön: içeriden dışarıya (Oda → Limbo). Ok ters gösteriyorsa Flip Direction.
  7. Entities sekmesi → drawable'ı seç → Add Object(s) as Entity, entity'ye odasını ata.
7. Export
  1. Export edilecek her şeyi seç. Gizli obje export edilmez.
  2. Sollumz panelinden export al (XML çıkar).
  3. XML'leri RPF Explorer'a sürükle. CodeWalker .ydr .ytyp .ybn'ye çevirir.
8. Ymap ve oyuna yükleme
  1. CodeWalker'da dosyaların olduğu klasörü proje olarak aç.
  2. Ymap ekle → yeni entity → arketip adını varsayılan prop_alien_egg_01 yerine kendi MLO adınla değiştir.
  3. Konum: Blender'da Konum kopyasını seç → General → Object Location & Rotation Tools → en soldaki butonla koordinatı kopyala, CodeWalker'a yapıştır.
  4. Flags ve extents hesapla, ymap'i kaydet, manifest oluştur.
  5. Adım 4'teki gibi resource'a koy, sunucuda test et.
